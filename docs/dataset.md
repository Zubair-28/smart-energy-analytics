# Dataset

The included `energy_demo.csv` is synthetic, generated by `processing.pipeline.generate_demo`. It contains hourly UTC readings for configurable building entities over a configurable number of days. It includes seasonal daily/weekend patterns, noise, and three documented injected spikes for detector demonstrations. It is not real household data and must not be presented as such.

For a final academic experiment, substitute a public electricity dataset after recording its source URL, license, row count, schema, time resolution, missingness, duplicates, and semantic treatment of negative values.
